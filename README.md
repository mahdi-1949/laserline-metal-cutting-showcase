# لیزرلاین | نمونه‌کار برش لیزر فلزات

این مخزن شامل سورس کامل نمونه‌کار یک وب‌سایت فارسی و راست‌چین برای معرفی خدمات برش لیزر فلزات است.

## صفحه‌ها

- خانه (`index.html`)
- خدمات (`services.html`)
- نمونه‌کارها (`projects.html`)
- درباره ما (`about.html`)
- تماس با ما (`contact.html`)

## فایل‌ها

- `assets/` شامل سبک‌ها، تعامل‌های منو و فرم، و favicon است.
- `dist/` نسخه استاتیک آماده انتشار را نگه می‌دارد.

نمونه پروژه‌ها و اطلاعات تماس داخل سایت نمایشی هستند و برای استفاده واقعی باید با اطلاعات شرکت جایگزین شوند. تصاویر صنعتی از Unsplash بارگذاری می‌شوند. فرم تماس در این نسخه نمایشی اطلاعات را ارسال نمی‌کند.
